# Seeed T1000-E hardware bring-up

**Status: NOT flashable.** The existing `firmware/t1000e` target is a generic nRF52840 core compilation probe, not a T1000-E port. Never upload its output.

## Required implementation before flashing

- [ ] Verify the exact Seeed T1000-E hardware revision and its documented pin map.
- [ ] Select a compatible bootloader, board definition, and partition/memory layout.
- [ ] Implement the radio driver and verify SPI, BUSY, DIO, RESET and RF switch control against the actual schematic.
- [ ] Integrate GPS and persistent identity/keys with explicit power-management behavior.
- [ ] Provide a non-transmitting startup self-test and require an explicit opt-in to transmit.
- [ ] Add a real board-specific PlatformIO environment and compile it in CI.
- [ ] Verify firmware size, bootloader compatibility and rollback/recovery instructions.
- [ ] Test on physical hardware: boot, radio RX/TX, encrypted DATA, SOS, sleep/wake, reset recovery.

Passing `nrf52840_compile_probe` proves only that the portable GhostWave core compiles. It does not verify radio operation or safe flashing.
