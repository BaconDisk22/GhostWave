# GhostWave physical hardware test worksheet

Status: NOT TESTED. Do not flash the generic nRF52840 compile probe.

For each test session record:
- Device model, PCB and baseboard revisions, manufacturer pinout and bootloader evidence
- Firmware commit, binary SHA-256, build log and approved flash/recovery method
- Antenna, RF configuration, regional compliance, power source, date and operator
- Boot, receive-only, reboot, storage recovery, encrypted message, SOS/ACK, retries and link loss
- Expected result, actual result, serial log reference, pass/fail and issue link

A blank field is not a pass. Physical transmission is prohibited until verified board integration and explicit operator authorization. The release gate stays blocked.
